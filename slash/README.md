# 乱刃 · 斩击大乱斗

单文件 top-down 斩击混战小游戏（HTML5 Canvas + 原生 JS，零依赖、零构建）。

## 运行

直接用浏览器打开 `index.html` 即可（无需服务器）。

## 玩法

- 配装界面从 **6 种斩击** 中选 2 种，分别装入左槽 / 右槽：

| 斩击 | 特点 |
| --- | --- |
| 迅斩 | 冷却 0.45s，快速连打消耗 |
| 重斩 | 蓄力大扇形，高伤害 + 强击退 |
| 突斩 | 向前疾冲后挥斩，位移进攻一体 |
| 旋斩 | 360° 周身回旋，防围殴 |
| 剑气 | 远程飞行剑气，消耗牵制 |
| 穿刺 | 狭长直线突刺，远距离高伤 |

- 进入战场后与 5 名 AI 剑客自由混战（FFA），AI 随机携带两种斩击，会索敌、走位、环绕、按冷却出招。
- 率先取得 **10 杀** 获胜；阵亡 2.5 秒后重生（1.5 秒无敌）。

## 操作

- `WASD` / 方向键：移动
- 鼠标：瞄准
- 鼠标左键 / `J`：左槽斩击（可按住连发）
- 鼠标右键 / `K`：右槽斩击
- `M`：静音
- 结算后 `R` 再战（AI 重新随机斩击）、`B` 返回配装
