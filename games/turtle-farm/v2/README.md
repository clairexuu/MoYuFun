# 玄武农场 v2

伪装成 Excel 采购计划表的种田游戏，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/turtle-farm.md`。

## 玩法

- 打开就是一张表「玄武物流 · 农产品采购计划」，第一次播种才开始计时。4 × 4 的地块（B9:E12）跟着玄武走 30 天，穿过草原、雨林、沙漠、雪原；第 6、12、18、24、30 天是集市。
- 每天 8 秒。每个日终，作物在喜欢的地形 +3 点、普通地形 +2 点、讨厌的地形 +0 点并受一次伤；点数到 `2 × 周期` 成熟，伤数超过「耐」就枯萎。集市日对所有作物都算普通。
- 地块的条件格式：生长中是黄色数据条（受过伤变红），左边的箭头是今天地形对它的喜 / 平 / 忌；成熟变绿，最后一天显示「快烂」，再放一个日终就烂掉；枯萎是红色。
- 表头一行是今天和后 5 天的地形；「适宜度」一行按选中的种子标喜 / 平 / 忌；集市列下面是热销（×2）和滞销（×0.5）。
- 集市日时间停住，卖完点「离开集市」（或回车）才继续；第 30 天是「靠岸结算」。平时收购商随时按售价一半收货。
- 起始 40 金，余额在 K1 和状态栏「求和」。第 30 天结束时攒够 800 算赢，1500 富甲一方。

## 操作

- 鼠标 / 触摸：点空白地块播种，点成熟作物收获；从一块地拖动会对经过的地重复同一个动作
- 种子目录（I3:P10）点一行，或按 `1`–`8`：选种子
- 仓库「卖出」/「全部卖出」：卖出作物
- 空格：暂停 / 继续（暂停时照样能播种、收获、卖出）；切到后台自动暂停
- `Esc`：老板键，切到「采购汇总」普通表格并冻结时间，再按一次回来（也可以点工作表标签）
- `M`：声音开关（默认关）

## 成就

每趟航程一局（第一次播种发 `start` … `end`），每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前，顺序 `voyage, no_loss, tycoon`。

| key | 名称 | 条件 |
| --- | --- | --- |
| `thrive` | 风调雨顺 | 收获一株每个日终都在喜欢地形里的作物 |
| `hot_seller` | 抢手货 | 一次集市卖出至少 5 个热销作物 |
| `voyage` | 满载而归 | 航程结束时金币 ≥ 800 |
| `no_loss` | 寸草不枯 | 金币 ≥ 800，且整趟没有作物枯萎或烂掉 |
| `tycoon` | 富甲一方 | 航程结束时金币 ≥ 1500 |

战绩：`{ rounds: 1, wins: 0|1, harvests: 收获数, coins: 最终金币 }`。
