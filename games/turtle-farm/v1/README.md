# 玄武农场

在神龟背上种田，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/turtle-farm.md`。

## 玩法

- 4 × 4 的田长在玄武背上，30 天里穿过草原、雨林、沙漠、雪原；第 6、12、18、24、30 天是集市。
- 每天 12 秒（2× 时 6 秒）。每个日终，作物在喜欢的地形 +3 点、普通地形 +2 点、讨厌的地形 +0 点并受一次伤；点数到 `2 × 天数` 成熟，伤数超过「耐」就枯萎（🥀）。集市日对所有作物都算普通。
- 成熟的作物在地里放 3 个日终会烂掉；收进仓库的作物不限量、不会坏。
- 只能在集市卖。每个集市有一种热销（×2）和一种滞销（×0.5）。
- 预报条显示今天和后 5 天的地形；选中的种子会给每一格描边：绿 喜、灰 平、红 忌。
- 起始 20 金币，第 30 天结束时攒够 800 算赢，1500 富甲一方。
- 暂停时照样能播种、收获、卖出；切到后台会自动暂停。

## 操作

- 鼠标 / 触摸：选种子，点空地播种，点成熟作物收获；从一块地拖动会对经过的地重复同一个动作（播种或收获）
- 集市面板：点作物卖出，或「全部卖出」；第 30 天还有「靠岸结算」
- `1`–`8`：选种子；空格：暂停 / 继续；`F`：1× / 2×；`M`：静音

## 成就

每趟航程一局（`start` … `end`），每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前，顺序 `voyage, no_loss, tycoon`。

| key | 名称 | 条件 |
| --- | --- | --- |
| `thrive` | 风调雨顺 | 收获一株每个日终都在喜欢地形里的作物 |
| `hot_seller` | 抢手货 | 一次集市卖出至少 5 个热销作物 |
| `voyage` | 满载而归 | 航程结束时金币 ≥ 800 |
| `no_loss` | 寸草不枯 | 金币 ≥ 800，且整趟没有作物枯萎或烂掉 |
| `tycoon` | 富甲一方 | 航程结束时金币 ≥ 1500 |

战绩：`{ rounds: 1, wins: 0|1, harvests: 收获数, coins: 最终金币 }`。中途「重新开始」也会发送一次（`wins: 0`）。
