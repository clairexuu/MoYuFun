# 代码找不同

VS Code 对比视图里的找不同，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/bug-hunt.md`。

## 玩法

- 左边是原文件，右边是改过几处的副本，改动不高亮。点中改动（左右都可以），两侧这一行就像真正的 diff 一样标红/标绿；点错扣 3 秒，记号下出现红色波浪线。
- 一局一个倒计时：每轮开始时加上这一轮的时间，没用完的时间带进下一轮。时间用完一局结束，得分是找到的改动数。
- 轮次越往后改动越多（3 → 9 处）、文件越长（1 → 3 段代码）、改动越隐蔽（`true`/`false`、`const`/`let` → `===`/`==`、`<`/`<=`、`&&`/`||` → 少一个 `!`、参数互换、字符串里改一个字母）。
- 代码来自内嵌的 24 段手写 TypeScript，改动由 14 种变异算子按种子生成，每行最多一处，不用易混字符。

## 操作

- 鼠标 / 触摸：点代码；滚轮或拖动：两侧同步滚动；方向键 / PageUp / PageDown 也能滚
- `Tab`：提示一处改动（扣 10 秒，多按会轮换）
- `Esc`：老板键，切到一份普通的对比视图并暂停；再按一次继续
- `M`：声音开关（默认关闭）
- 结束后点编辑器或按 `Enter` 重开

## 成就

每局（`start` … `end`）每个 key 最多发送一次，都在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `quick_eye` | 眼疾手快 | 同一轮里两次找到改动相隔 ≤ 2 秒 |
| `perfect` | 零误报 | 第 3 轮起，一轮里不点错、不用提示 |
| `level_5` | 代码审查 | 一局通过 5 轮 |
| `finds_30` | 火眼金睛 | 一局找到 30 处 |
| `level_10` | 首席审查官 | 一局通过 10 轮 |

战绩：`{ rounds: 1, levels: 通过轮数, finds: 找到改动数 }`。
