# 表格贪吃蛇

伪装成 Excel / VS Code 的贪吃蛇，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/sheet-snake.md`。

本文件也是办公伪装外壳的参考实现（`docs/design/office-camouflage.md` D7）：新游戏整段复制 `index.html` 里的「画布小工具」「Excel chrome」「VS Code chrome」三节，调用 `excelContentRect(box)` / `vscodeContentRect(box)` 拿到游戏区域，先画外壳再画内容。

## 玩法

- Excel：选中的单元格是蛇头，绿色（好）单元格是蛇身，红色（差）单元格是食物，黄色（中性）单元格是限时奖励，格子里的数字就是它现在值多少分。
- VS Code：光标是蛇头，选区是蛇身，红色波浪线是食物，黄色波浪线是限时奖励；第 80 列标尺和文件最后一行是墙。
- 普通食物 10 分，每吃一个快 4 ms（150 → 65 ms 一步）。每第 4 个普通食物后出现一个限时奖励，6 秒内吃到得 20 + 5 × 剩余整秒（最多 50），最后 2 秒闪烁。
- 撞墙：`#REF!` / `TypeError`；撞到自己：`循环引用` / `RangeError`。分数显示在状态栏「求和」/ 问题数 ⚠。
- 网格在每局开始时按窗口大小定下，整局不变。

## 操作

- 方向键 / WASD，或在屏幕上滑动：转向（第一次转向开局）
- 空格 / 轻点：开始；结束后重来
- `F2`：切换 Excel / VS Code（记在 localStorage，并发送新的 `disguise`）
- `Esc`：老板键，隐藏所有游戏信息并冻结；再按 Esc 回来后暂停，方向键继续
- `M`：声音开关（默认关）

## 成就

每局（`start` … `end`）每个 key 最多发送一次，都在达成的那一步立即发送，因此总在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `len_10` | 小计 | 蛇身长到 10 格 |
| `len_30` | 合计 | 蛇身长到 30 格 |
| `bonus_3` | 超额完成 | 一局吃到 3 个限时奖励 |
| `full_speed` | 满负荷 | 达到最高速度（吃到第 22 个普通食物） |
| `score_500` | 季度冲刺 | 一局得到 500 分 |

战绩：`{ rounds: 1, foods: 吃到的食物和奖励个数, bonus: 吃到的奖励个数 }`。
