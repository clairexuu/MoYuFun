# 影子行者

一屏一关的解谜平台跳跃，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/shadow-walk.md`。

## 玩法

- 小影怪只能站在实心上：墨石（固定地面）或道具投下的影子。被照亮的地方是空气，掉出画面就重来本关。
- 拖动轨道上的灯笼，箱子、木板和风车的影子会伸长、倾斜、转动，变成桥、坡道和升降台；升起的影子会把你往上推，推不出去就被挤扁。
- 十关一局，按顺序，不存档。每关按用时给金 / 银 / 铜牌。同一关掉落 3 次或超过 60 秒可以跳过。
- 碰撞用 6 px 格子（160 × 90），每帧按灯笼位置重建；物理是固定 60 Hz、无随机的 tick，所以录制的解法能逐帧重放。

## 操作

- `A / D` 或 `← / →`：移动；`空格 / W / ↑`：跳
- 鼠标或手指在画面上按住拖动：灯笼移到轨道上最近的点（每秒最多 240 px）
- `Q / E`：用键盘沿轨道移动灯笼
- 触屏：出现 ◀ ▶ 跳 按钮
- `R`：重来本关（不算跌落）；`M`：静音；`G`：显示碰撞格子
- URL 加 `?rec`：过关时在控制台打印本关输入，格式同 `SOLUTIONS`

## 成就

每局（`start` … `end`）每个 key 最多发送一次，结算时在 `stats`、`end` 之前。`start` 在本局第一次操作（移动、跳、动灯笼）时发送。

| key | 名称 | 条件 |
| --- | --- | --- |
| `halfway` | 半影 | 通过第 5 关 |
| `crushed` | 被挤扁了 | 被移动的影子挤扁一次 |
| `gold_5` | 疾影 | 一局内拿到 5 枚金牌 |
| `clear` | 影归 | 不跳过任何一关，走完十关 |
| `deathless` | 不见光 | 走完十关且一次没掉落、没被挤扁 |

战绩：`{ rounds: 1, wins: 全通且没跳过 ? 1 : 0, levels: 过关数, golds: 金牌数 }`，在走完第 10 关或点「放弃」时发送；第一次操作前放弃不发送任何消息。
