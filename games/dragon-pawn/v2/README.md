# 当铺账房（dragon-pawn v2）

伪装成 Excel 台账的典当审计，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/dragon-pawn.md`。v1（龙的当铺，手册鉴定 + 砍价）在 `../v1/`，不再修改。

## 玩法

- 每位客人是台账底部新的一行：物品、工坊、矿脉、印记、铭文、宝石、材质、行情、要价。
- 表头冻结着审核规则，第 1 天 2 条，之后每天多一两条，共 9 条。违反任一条 → 拒；要价超过行情一半 → 压价（按要价六折还价）；都没问题 → 收。
- 客人按节奏不停地来，待处理超过 5 行，最早的那位走掉并赔偿 30。
- 每天结束切到「对账」工作表：每笔的成交价、实情、应有处理、盈亏、错失和原因。
- 五天一局，分数是净利润；达到 3,000 完成指标。

## 操作

- `1`/`A` 收 · `2`/`S` 压价 · `3`/`D` 拒；`↑` `↓` 选行
- 鼠标 / 触摸：点处理格里的按钮，点一行的其他格子选中它
- `Enter`：对账后进入下一天
- `Esc`：老板键（切到销售汇总表，时间冻结，再按一次回来）
- `M`：声音（默认关）

## 成就

每局（`start` … `end`）每个 key 最多一次，日终/月末时在 `stats`、`end` 之前发送。

| key | 名称 | 条件 |
| --- | --- | --- |
| `full_month` | 月末结账 | 做完五天 |
| `sharp_eye` | 火眼金睛 | 一局拒收 15 件赝品 |
| `bargain` | 砍价高手 | 一局对虚高真品压价 10 次 |
| `clean_day` | 账实相符 | 某一天全部正确 |
| `target` | 完成指标 | 净利润 ≥ 3,000 |
| `perfect` | 零差错 | 五天全部正确 |

战绩：`{ rounds: 1, wins: 0|1, fakes: 拒收赝品数, profit: max(0, 净利润) }`。
