# 龙的当铺

地牢门口的龙之当铺：验宝、砍价、放贷，单文件（DOM + 一块画宝物的 canvas，原生 JS，零依赖、零构建）。设计文档：`docs/games/dragon-pawn.md`。

## 玩法

- 每天最多 6 位勇者、一根 70 秒的蜡烛。勇者押宝物换金币，说的工坊、矿脉都是真的。
- 对照鉴定手册查印记、铭文、宝石、材质四处，不符就是赝品。私下标记疑点后「指出疑点」：说中了要价降到四成（露馅），冤枉好人则对方更不耐烦、要价涨一成。
- 出价低于要价会被还价或被冒犯，耐心耗尽就走人。
- 当晚结算：活着回来的连本带利（1.5 倍）赎回，没被识破的骗子卷款溜走；回不来的宝物入库，赝品一文不值。
- 起始 800 金，每天开门交 30 金管理费，交不起就关门大吉。第七天结束时宝库达到 1000 金获胜。

## 操作

- 鼠标 / 触摸：点宝物部位或下方按钮查看、标为疑点；拖动滑块或 −/+ 出价
- `1`–`4`：查看印记 / 铭文 / 宝石 / 材质；`X`：标记当前部位
- `←` `→`：出价 ±5（`Shift` ±50）；`Enter`：出价（也用于开张、天亮了、再开一家）
- `B`：鉴定手册（`Esc` 合上，蜡烛不停）；`M`：静音

## 成就

每局（`start` … `end`）内判定，每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `sharp_eye` | 火眼金睛 | 一局内当面识破 5 件赝品 |
| `first_hoard` | 第一件宝贝 | 第一件真品入库 |
| `big_haul` | 稀世珍宝 | 价值 ≥ 300 的真品入库 |
| `loan_shark` | 龙息高利 | 一局累计利息 ≥ 500 |
| `win` | 富可敌国 | 第七天结束宝库 ≥ 1000 |
| `clean_win` | 明察秋毫 | 获胜，没冤枉过好人，宝库里没有赝品 |

战绩：`{ rounds: 1, wins: 0|1, fakes: 识破件数, hoard: 宝库价值（≤ 20000） }`。
