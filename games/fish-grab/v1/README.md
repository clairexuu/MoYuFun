# 抢鱼 · 3v3 夺鱼战

单文件 3v3 夺鱼小游戏（HTML5 Canvas + 原生 JS，零依赖、零构建），斩击系统沿用「乱刃」v4。设计见 `docs/design/fish-grab.md`。

## 运行

直接用浏览器打开 `index.html` 即可（无需服务器）。

## 玩法

- 配装界面从 6 种斩击中选 2 种（与乱刃相同），分别装入左槽 / 右槽。
- 青鱼门（你 + 阿青、小蓝）对赤鲤帮（赤瞳、红鲤、丹砂），无友伤。
- 碰到场地中央的金鱼即可拾取；持鱼者移速 70%、无法使用右槽，受到任何伤害都会掉鱼（0.6 秒内无人可捡）。
- 带鱼进入己方阵地（左蓝右红）得 1 分，2 秒后中央刷出下一条鱼；掉落的鱼 10 秒无人碰会回到中央。
- 先得 **5 分** 获胜；5:00 时领先方获胜，平分则加时，下一次得分决胜。
- 阵亡 3 秒后在己方阵地重生（1.5 秒无敌）。

## 操作

- `WASD` / 方向键：移动；鼠标：瞄准
- 鼠标左键 / `J`：左槽斩击；鼠标右键 / `K`：右槽斩击（持鱼时不可用）
- `M`：静音；结算后 `R` 再战、`B` 返回配装

## 成就与战绩

| key | 名称 | 条件 |
| --- | --- | --- |
| `first_score` | 摸到鱼了 | 亲手送回一条鱼 |
| `steal` | 截胡 | 打掉敌方持鱼者的鱼，并在 3 秒内亲手捡起 |
| `escort` | 护驾 | 队友（AI）持鱼时击倒 3 名敌人 |
| `hat_trick` | 帽子戏法 | 单局亲手送回 3 条鱼 |
| `first_win` | 满载而归 | 赢下一局 |
| `shutout` | 零封 | 对手一分未得赢下一局 |

每个 key 每局最多发送一次；结算顺序为成就 → `stats { rounds, wins, scores, kills }` → `end`。
