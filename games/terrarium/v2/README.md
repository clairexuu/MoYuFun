# 生态瓶 v2

伪装成 Excel 的生态瓶实验，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/terrarium.md`。

## 玩法

- 工作表标签 实验1–实验5 各是一瓶：预算、光照、必选物种、扰动和目标都不同。
- 配置表里点 ▲▼ 调数量（或 ↑↓ 选行、+/− 调整），光照是下拉单元格，`开始实验`（Enter）。
- 实验中盯住监测面板（变黄 / 变红）和三张折线图，三种干预每瓶各一次：
  - 补种水草（Q）：水草 +15。
  - 开盖通气（W）：48 小时内 O₂ 每小时向 16 回升 30%。
  - 遮光一天（E）：24 小时无光、呼吸 ×0.8、藻类额外死亡 0.5/天。O₂ 会降。
- 1× 下 100 天约 60 秒；空格暂停，1 / 2 / 3 切换 1× / 2× / 4×。窗口失焦自动暂停。
- 撑到期限不崩溃 ★，再按两个附加目标各加一星。最佳星数存在 localStorage。
- Esc 老板键（冻结时间，显示一张费用表），M 开关声音（默认关）。
