# 生态瓶

封瓶前定好一切的生态瓶模拟，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/terrarium.md`。

## 玩法

- 用 100 贝壳往瓶里放藻类、水草、苔藓、小虾、螺、跳虫、细菌、沙和炭，选好光照（背阴 / 窗边 / 灯下），然后封瓶。至少要有一种动物和一种植物。
- 封瓶后只能旁观：暂停、1× / 2× / 4×（每秒 1 / 2 / 4 天）或跳到结局。
- 第 100 天时动物和植物都还活着就算成功；所有动物或所有植物灭绝的那天结束，结算页给出死因、种群曲线和建议。
- 「再来一瓶」回到配置页，保留上一瓶的配置。

## 模型简介

- 每小时一步的确定性差分方程（2,400 步一局），不含随机；随机数只用于精灵的位置和动作。同样的配置永远同样的结局。
- 气体是一个封闭池：氧气 + 二氧化碳 = 20。生产者只在有光、有二氧化碳时产氧；所有生物昼夜都在呼吸，细菌分解废物还要额外耗氧。
- 藻类超过半容量会成片死亡；动物吃饱才繁殖，食物接近吃不到的“底线”时会饿死；没有分解者时废物越过阈值（30，放炭后 60）就开始毒死动物。
- 光照决定强度、日照时长和热量（呼吸倍率）。灯下长得快，但更热，苔藓还会被晒伤。
- 死因按体重统计缺氧、中毒、饥饿三类，取最大者；缺氧开始时藻类 ≥ 40 则判为藻华。

## 操作

- 鼠标 / 触摸：增减物品、选光照、封瓶、调速度
- `Enter`：封瓶 / 再来一瓶
- 空格：暂停或继续
- `1` / `2` / `3`：1× / 2× / 4×
- `S`：跳到结局
- `M`：静音

## 成就

每次封瓶一局（`start` … `end`），每个 key 每局最多发送一次，只在成功时于结算发送，在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `sealed_100` | 百日生机 | 撑到第 100 天 |
| `full_house` | 七族同瓶 | 第 100 天七种生物全部存活 |
| `frugal` | 小本经营 | 花费 ≤ 60 贝壳并成功 |
| `shade_win` | 背阴之地 | 选背阴并成功 |
| `calm` | 风平浪静 | 100 天每天都健康（最低氧气 ≥ 8，最高废物 < 15） |

战绩：`{ rounds: 1, wins: 0|1, days: 结束天数, species: 结束时存活物种数 }`。
