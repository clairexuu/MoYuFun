# 纸飞机邮差

单键滑翔竞速，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/paper-plane.md`。

## 玩法

- 按住机头上扬（到 +40°），松开机头下沉（到 −30°）。飞机沿机头方向飞：俯冲换速度，爬升耗速度；速度低于 110 失速，自动低头直到回到 170。
- 烟囱冒出的炊烟把飞机往上托（不加速度），风区推着飞机走；没有推力，炊烟是唯一的能量来源。
- 穿过邮筒上方的虚线框就算送达；错过一个 +5 秒。撞到屋顶、烟囱、电线、电线杆或灯笼 +3 秒，停 1 秒（时钟照走）后从上一个检查点重飞。
- 一天三程：晨雾小镇 → 风车坡 → 灯会夜，每程有金 / 银 / 铜时间；任一程超过上限（135 / 160 / 190 秒）就天黑结束。
- 模型是 120 Hz 定步的纯函数 `stepRun(run, hold)`，不用随机数；`rng` 只给炊烟和飞鸟做装饰。

## 操作

- 按住鼠标 / 触摸 / 空格：机头上扬（开场时第一次按下即起飞）
- `Enter`：下一程 / 再送一天
- `R`：重新开始这一天
- `M`：静音

## 成就

一天一局（第 1 程起飞时 `start` … `end`），每个 key 每局最多发送一次，在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `updraft` | 扶摇直上 | 在同一股炊烟里连续被托升 300（任一程） |
| `deliver_all` | 一封不落 | 一程零漏信 |
| `gold` | 金邮戳 | 任一程跑进金牌时间 |
| `all_gold` | 金牌邮差 | 同一天三程全金 |
| `flawless` | 毫发无伤 | 送完一天零撞毁 |

战绩：`{ rounds: 1, wins: 0|1, letters: 本局送达信件, golds: 金牌数 }`。

## 测试

```bash
node test_headless.js            # 线路派生值与规则、飞行模型、三条录制脚本回放（时间、零撞毁、金牌）、完整一天 / 天黑 / 罚时 / 重来的消息顺序
node test_headless.js --record   # 束搜索重新录制三条脚本（改常数或线路后用），打印新的十六进制串
```
