# 表格扫雷

Excel 皮肤的无猜扫雷，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/sheet-mines.md`。

## 玩法

- 盘面是一块灰色单元格；翻开后数字是周围的雷数（按条件格式着色），空白是 0，标记是红色填充 + 批注三角，踩雷显示 `#N/A`。
- 首击格及周围 8 格不放雷，所以第一下必定展开一片；每盘都由内置求解器（单格规则、两两/子集规则、全局雷数）验证能纯逻辑清完，最多重试 1000 次，仍不行就用最后一盘。
- 三张工作表：初级 9×9/10、中级 16×16/40、高级 30×16/99。状态栏：平均值 = 进度，计数 = 剩余雷数，求和 = 用时（秒）。

## 操作

- 左键 / 轻触：翻开；点一个周围标记数等于数字的格子，展开其余邻格（和弦）
- 右键 / 长按 / `F`：标记
- 方向键移动选中格，空格 / Enter 翻开
- 工作表标签或 `PageUp` / `PageDown`：换难度（已开局的算一局负）
- `Esc`：老板键；`M`：声音（默认关）

## 成就

每局（首击 `start` … 胜负 `end`）每个 key 最多一次，结算成就在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `batch` | 批量处理 | 一局内第 15 次有效和弦（局中发送） |
| `win_easy` / `win_medium` / `win_hard` | 初审 / 复核 / 终审通过 | 赢下对应难度 |
| `no_flags` | 心中有数 | 中级或高级获胜且本局没插过标记 |
| `quick_easy` | 手快 | 初级 ≤ 20 秒获胜 |
| `quick_hard` | 准点下班 | 高级 ≤ 300 秒获胜 |

战绩：`{ rounds: 1, wins: 0|1, cells: 本局翻开的安全格数 }`。
