# 升官记

2048 职场版，单文件（DOM + 原生 JS，零依赖、零构建）。设计文档：`docs/games/promotion-2048.md`。

## 玩法

- 4 × 4 棋盘，滑动后两个相同职位合并成更高一级：实习生 → 专员 → 组长 → 主管 → 经理 → 总监 → 副总 → 总经理 → CEO → 董事长 → 财务自由（2048）。
- 每局一次「背锅侠」撤回一步。合成财务自由后可选「继续卷」或「退休」，都算赢；否则无路可走时结束。

## 操作

- 方向键 / WASD，或在棋盘上拖动 / 滑动：滑动
- `Z`：撤回一步（每局一次）
- `M`：静音
- `R`：重新开始

## 成就

每局内判定，每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `manager` | 升任经理 | 合成经理 |
| `double` | 双喜临门 | 一步之内合成两个总监或更高 |
| `ceo` | 走上巅峰 | 合成 CEO |
| `no_undo` | 不背锅 | 本局未撤回时合成 CEO |
| `freedom` | 财务自由 | 合成财务自由 |

战绩：`{ rounds: 1, wins: 财务自由 ? 1 : 0, merges }`，在无路可走、退休，或移动过之后中途重开时发送。
