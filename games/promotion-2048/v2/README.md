# 表格 2048（v2）

2048 伪装成 Excel 预算表，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/promotion-2048.md`。v1 是职场主题的「升官记」，已发布，不再修改。

## 玩法

- 棋盘是预算表的 C4:F7。滑动后两个相同的数合并成两倍，三色刻度条件格式（白 → `#ffeb84` → `#63be7b`）跟着数值变色，G/H 列和第 8 行的合计、占比实时更新。
- C10「累计核减」是分数，C11「历史最佳」存在 `localStorage`。
- 合并后选中框跳到本步最大的合并格，编辑栏显示 `=D5+E5`；没有合并时回到 C10，显示 `=SUM(合并记录!C:C)`。
- 状态栏：撤销 1、平均值、计数、最大值、求和（= 分数）。
- 每局撤销一次。无路可走弹出「无法完成此操作。」，确定重开。合成 2048 弹出「继续(C) / 停止(S)」，都算赢。

## 操作

- 方向键 / WASD，或拖动 / 滑动：移动
- `Ctrl+Z` / `Cmd+Z`（或单按 `Z`）、标题栏 ↶：撤销
- `Ctrl+N`、`R`、功能区「新建」：新开一局（浏览器可能占用 Ctrl+N）
- 弹窗：`Enter` / 空格 = 默认按钮，`C` / `S` = 继续 / 停止
- `Esc`：老板键（冻结并换成普通预算数字，再按恢复）
- `M`：声音开关（默认关闭）

## 成就

每局内判定，每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前。key 沿用 v1。

| key | 名称 | 条件 |
| --- | --- | --- |
| `manager` | 合成 32 | 合成 32 |
| `double` | 双倍合并 | 一步之内合成两个 64 或更大 |
| `ceo` | 合成 512 | 合成 512 |
| `no_undo` | 零撤销 | 本局未撤销时合成 512 |
| `freedom` | 合成 2048 | 合成 2048 |

战绩：`{ rounds: 1, wins: 合成 2048 ? 1 : 0, merges }`，在无路可走、停止，或移动过之后中途新建时发送。
