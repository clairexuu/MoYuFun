# 摸了个鱼

羊了个羊式叠牌消除，单文件（canvas + 原生 JS，零依赖、零构建）。设计文档：`docs/games/tile-stack.md`。

## 玩法

- 点击没被压住的牌放进下方 7 格槽位，三张相同即消除；槽位放满 7 张就输，桌面、侧堆、暂存行和槽位都清空就赢。
- 两关：第 1 关 3 种 18 张热身；第 2 关 12 种 108 张，6 层桌面加左右两个侧堆。
- 关卡由固定种子生成，保证有解（洗牌后不再保证）。
- 第 2 关道具各一次：移出（槽位前 3 张移到暂存行）、撤回（退回上一张，消除后不可用）、洗牌。

## 操作

- 鼠标 / 触摸：点牌、点道具
- `M`：静音

## 成就

每关一局（`start` … `end`），每个 key 每局最多发送一次，结算时在 `stats`、`end` 之前。

| key | 名称 | 条件 |
| --- | --- | --- |
| `combo_5` | 手速惊人 | 最近 5 次消除在 10 秒内（任一关） |
| `tutorial` | 入职 | 通过第 1 关 |
| `clear` | 下班 | 通过第 2 关 |
| `no_props` | 赤手空拳 | 不用道具通过第 2 关 |
| `close_call` | 悬崖勒马 | 槽位曾到 6 张仍通过第 2 关 |

战绩：`{ rounds: 1, wins: 0|1, tiles: 消除张数 }`。
